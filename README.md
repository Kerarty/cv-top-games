# BALANCE LAB

Интерактивное резюме геймдизайнера. Не список достижений, а рабочий
инструмент: merge-автобатлер, который собирается руками, запускается в бой
и пересчитывается целиком по таблице характеристик.

**Открыть:** https://kerarty.github.io/cv-top-games/

Исходники: https://github.com/Kerarty/cv-top-games

Отклик на вакансию **Game Designer** в Top App Games (LUDUS — тактический
мерж-автобатлер).

## Что внутри

Три вкладки смотрят в одну модель данных. Правка ячейки в таблице мгновенно
меняет юнита в бою и перестраивает графики. Это и есть главный довод
страницы: источник правды ровно один, как в настоящем пайплайне.

- **Бой** — сетка 4×4, слияние двух одинаковых в юнит тира выше. По кнопке
  поле расширяется до 8×4: слева твой отряд, справа противник, между ними
  разделитель. Бой проигрывается по тикам: юниты сближаются, бьют, теряют
  здоровье по полосам, умирают. Есть перемотка скоростью 1× / 2× / 4×.
- **Таблица** — настоящие поля ввода. Правка переписывает модель, а не
  картинку, и работает даже посреди боя. Кнопка копирует таблицу в буфер
  как TSV — можно вставить прямо в Google Sheets.
- **Графики** — TTK по тирам, рост урона, кривая стоимости, прогон
  1000 боёв и вердикт с объяснением, что именно сломано.

## Файлы

| Файл | Что в нём |
|---|---|
| `index.html` | Разметка. Текста нет — он в `content.js` |
| `styles.css` | Стили, тёмная тема, правила для печати в PDF |
| `content.js` | **Весь текст, русский и английский.** Правится здесь |
| `balance.js` | Модель: архетипы, тиры, экономика. Каждое число с обоснованием |
| `engine.js` | Слияние, бой по тикам, детерминированный генератор, симуляция |
| `lab.js` | Интерфейс лаборатории: поле, бой, таблица, графики, прогон |
| `main.js` | Язык, вкладки, скролл |
| `assets/resume.pdf` | Резюме одной страницей для скачивания |

Правьте `content.js`, чтобы поменять текст, и `balance.js`, чтобы поменять
числа. Остальное трогать не нужно.

## Запуск

Сборки нет. Достаточно открыть `index.html` двойным кликом — или отдать
папку на любой статик-хостинг.

## Две версии резюме

Интерактивная страница и PDF — не одно и то же, а два способа донести одно
и то же. Интерактивная показывает, как считается баланс; PDF нужен там,
где игру открыть неудобно или она не загрузилась, — одна страница A4,
вложение к письму.

Кнопка «Сохранить страницу в PDF» в подвале — третий вариант: она печатает
саму страницу, а не отдаёт готовый файл. Разница существенна: печать
требует работающего скрипта, ссылка на файл — нет.

## Как считался баланс

Архетипы подобраны перебором, а не назначены на глаз. Считалась матрица
«каждый против каждого» по 400 боёв на пару. Исходный вариант был перекошен
насквозь: осадная выигрывала 100% боёв против всех, стрелок проигрывал
100% всем. Среднее отклонение от пятидесяти процентов было 47 пунктов,
сейчас — 7.

Три решения, которые пришлось принять по ходу:

1. **Сначала выровнять DPS и живучесть, потом развести по ролям.** Наоборот
   не выходит: на поле боя дальность решает всё, кто бьёт издалека — тот и
   выигрывает гонку, а три остальных архетипа превращаются в декорацию.
2. **Дальность стрелка урезана до двух клеток.** Разрыв в одну клетку по
   дальности давал стократный разгром: 21 пункт отклонения против 7.
   Проверялось и по здоровью — не помогает, виновата именно дальность.
3. **Очередность сторон и порядок атаки внутри тика случайны.** При
   фиксированном порядке зеркальный состав давал 83–93% вместо пятидесяти:
   исход решался тем, кто ходит первым, а не характеристиками.

Остался круг «осадная бьёт стрелка, стрелок бьёт ближнего, ближний бьёт
осадную». Это не изъян, а нормальный замкнутый круг: ни один архетип не
выигрывает у всех сразу.

Генератор детерминированный: тот же сид даёт тот же результат. Спорить о
балансе можно только с воспроизводимыми числами.

## Прогон винрейта

Вердикт считается не по тому, что игрок собрал на поле, а по эталонному
отряду против базовой линии: у обеих сторон одинаковый профиль тиров, но
разные архетипы — ближний бой с конницей против стрелка с осадной.

Так винрейт измеряет ровно одно: как архетипы соотносятся между собой.
Случайный состав мерил бы разброс тиров, а он достигает десятков
процентов. Свой отряд влияет на свободный бой, но не на метрику.

## Что умеет страница

- Работает с телефона, играется пальцем
- Ни одной внешней зависимости: ни одного CDN
- Русский и английский, выбор запоминается
- `Ctrl+P` печатает текстовое резюме в одну страницу A4
- Уважает `prefers-reduced-motion`
- Работает с клавиатуры: вкладки переключаются стрелками
